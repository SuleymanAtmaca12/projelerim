🔗 Çoklu Nöron — Katman

Birden fazla nöronu aynı katmana koyduğumuzda, her nöron aynı girişleri alır ama farklı ağırlıklarla işler. Bu sayede farklı örüntüler öğrenilir.

3 giriş
x₁, x₂, x₃
4 nöron katmanı
Her biri farklı öğrenir
4 çıktı
z₁, z₂, z₃, z₄
Python — NumPy
# ============================================================
# TEKLİ NÖRON HESABI (Elle Adım Adım)
# ============================================================
import numpy as np

# Girişler (özellikler)
x = np.array([2.0, 1.0])          # x1=2, x2=1

# Ağırlıklar
w = np.array([0.5, 0.8])          # w1=0.5, w2=0.8

# Bias
b = 0.5

# İleri hesap: z = x . w + b
z = np.dot(x, w) + b
print(f"z = {z}")                  # z = 2.3

# ============================================================
# ÇOKLU NÖRON KATMANI (Matrix İşlemi)
# ============================================================
# Giriş: 3 özellik
X = np.array([1.0, 2.0, 3.0])     # shape: (3,)

# Ağırlık matris: 4 nöron × 3 giriş
W = np.random.randn(4, 3)         # shape: (4, 3)

# Bias: her nöron için 1 tane
b = np.random.randn(4)            # shape: (4,)

# Tüm nöronları tek seferde hesapla!
Z = W @ X + b                      # shape: (4,)
print(f"Katman çıktısı: {Z}")

# TensorFlow/Keras ile aynı işlem:
import tensorflow as tf

layer = tf.keras.layers.Dense(units=4, input_shape=(3,))
x_t = tf.constant([[1.0, 2.0, 3.0]])  # (batch, features)
out = layer(x_t)
print(f"TensorFlow çıktı: {out}")

Köprüdeki Çarpılma — Ağırlıklar

Her bağlantının güç katsayısı: w (weight)

🎛️ Ağırlığı Değiştir, Sonucu Gör

Aşağıdaki kaydırıcıyla ağırlığı değiştirin. Ağırlık ne kadar büyük olursa o bağlantı o kadar önemli hale gelir.

1.5
0.5
2.0
📡

O bağlantı yok sayılır. Sinyal geçmez.

📶

Sinyal zayıflatılarak aktarılır.

📻

Sinyal değişmeden aktarılır.

📡

Sinyal güçlendirilerek aktarılır.

🔄

Python — Ağırlık İşlemleri
# ============================================================
# AĞIRLIK ÇARPIMI — TEMEL MANTIK
# ============================================================
import numpy as np

# Giriş sinyali
x = 5.0

# Ağırlık
w = 0.3

# Bağlantıdan geçen değer
signal = x * w
print(f"Sinyal: {x} × {w} = {signal}")  # 1.5

# ============================================================
# MATRİS ÇARPIMI (Katman için)
# ============================================================
# Çoklu giriş → çoklu çıkış
X = np.array([2.0, 3.0, 1.0])      # 3 giriş
W = np.array([                       # 2 nöron × 3 giriş
    [0.5, 0.3, 0.8],                 # nöron 1'in ağırlıkları
    [0.1, 0.9, 0.4],                 # nöron 2'nin ağırlıkları
])

Z = W @ X        # Matrix çarpımı
print(f"Çıktı: {Z}")   # iki nöronun ham çıktısı

# ============================================================
# TensorFlow/Keras — Ağırlıkları Görme
# ============================================================
import tensorflow as tf

layer = tf.keras.layers.Dense(2, input_shape=(3,))  # 3 giriş, 2 nöron
# Katmanı inşa et (build) — ağırlıklar oluşsun
layer.build((None, 3))
print("Ağırlıklar:")        # kernel: (3, 2)
print(layer.kernel.numpy())
print("Bias:")
print(layer.bias.numpy())   # shape: (2,)

Bias — Önyargı Terimi

Nöronun "eşiği" — bağımsız kaydırma kabiliyeti

🎯 Bias'ın Etkisini Gör

Aşağıda z = w·x + b eğrisinin bias'a göre nasıl kaydığını gözlemle:

b = 0: Doğru orijinden geçer. Nöron sadece x=0 üzerinde "uyanır".

💡 Saat Benzetmesi

Düşün: alarm saatin saat 7'de çalıyor (bias = -7). Bu, nöronun "ne zaman aktive olacağını" belirler. Bias olmadan, nöron sadece girişlerin tam olarak 0 olduğunda "uyuyabilir". Bias ile istediğin eşiği ayarlarsın.

📐 Matematiksel Anlamı

Bias yok: z = w·x → Doğru her zaman orijinden geçer
Bias var: z = w·x + b → Doğru özgürce kaydırılabilir

Bias, modele esneklik kazandırır. Bias olmadan, tüm doğrular orijinden geçmek zorunda kalır ve çok az örüntü öğrenilebilir.

Python — Bias Etkisi
# ============================================================
# BIAS OLMADAN vs BIAS İLE
# ============================================================
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)
w = 1.5

# Bias yok
z_no_bias = w * x
# Farklı bias değerleri
z_b_neg   = w * x + (-3)
z_b_zero  = w * x + 0
z_b_pos   = w * x + 3

plt.figure(figsize=(8, 5))
plt.plot(x, z_no_bias, 'gray',  linestyle='--', label='b=0 (orijinden geçer)')
plt.plot(x, z_b_neg,   'red',                   label='b=-3 (sola kayması)')
plt.plot(x, z_b_pos,   'green',                 label='b=+3 (sağa kayması)')
plt.axhline(0, color='white', linewidth=0.5)
plt.axvline(0, color='white', linewidth=0.5)
plt.grid(True, alpha=0.3)
plt.title("Bias'ın Etkisi: Doğruyu Kaydırmak")
plt.legend()
plt.show()

# ============================================================
# TensorFlow/Keras'ta Bias
# ============================================================
import tensorflow as tf

# Bias ETKİN (varsayılan)
layer_with_bias = tf.keras.layers.Dense(4, use_bias=True)

# Bias DEVRE DIŞI
layer_without_bias = tf.keras.layers.Dense(4, use_bias=False)

# Katmanı inşa et ve bias değerlerini gör
layer_with_bias.build((None, 3))
print("Bias değerleri:", layer_with_bias.bias.numpy())

Forward Pass

İleri yayılım: Girişten çıkışa hesap akışı

🔬 Adım Adım Forward Pass

Adım 1 / 5
🎯 Başlangıç: Giriş Verisi
Ham veriler modele beslenir. Örnek: x = [0.5, 0.8, 0.3]
x = [0.5, 0.8, 0.3]

📊 Tam Ağ Forward Formülü

Giriş
x
→
Katman 1
a¹ = f(W¹x + b¹)
→
Katman 2
a² = f(W²a¹ + b²)
→
Çıktı
ŷ = softmax(W³a² + b³)
Python — Forward Pass Sıfırdan
# ============================================================
# FORWARD PASS — SIFIRDAN EL İLE
# ============================================================
import numpy as np

def relu(x):
    return np.maximum(0, x)

def softmax(x):
    e = np.exp(x - np.max(x))
    return e / e.sum()

# Ağırlıklar (normalde eğitimle öğrenilir)
np.random.seed(42)
W1 = np.random.randn(4, 3)   # Katman 1: 4 nöron, 3 giriş
b1 = np.zeros(4)
W2 = np.random.randn(2, 4)   # Katman 2: 2 nöron, 4 giriş
b2 = np.zeros(2)

def forward_pass(x):
    print("=== FORWARD PASS ===")
    print(f"Giriş: {x}")

    # Katman 1
    z1 = W1 @ x + b1
    a1 = relu(z1)
    print(f"z1 (ham): {np.round(z1, 2)}")
    print(f"a1 (ReLU sonrası): {np.round(a1, 2)}")

    # Katman 2 (çıktı)
    z2 = W2 @ a1 + b2
    a2 = softmax(z2)
    print(f"z2 (ham): {np.round(z2, 2)}")
    print(f"a2 (Softmax sonrası): {np.round(a2, 2)}")
    print(f"Tahmin: Sınıf {np.argmax(a2)}")
    return a2

x_input = np.array([0.5, 0.8, 0.3])
output = forward_pass(x_input)

# ============================================================
# TensorFlow/Keras ile AYNI İŞLEM (daha temiz)
# ============================================================
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(4, activation='relu', input_shape=(3,)),
    tf.keras.layers.Dense(2, activation='softmax'),
])

x = tf.constant([[0.5, 0.8, 0.3]])
output = model(x)
print("TensorFlow çıktı:", output)

# ============================================================
# FARKLI DERİNLİKTE AĞLAR — TensorFlow/Keras
# ============================================================
import tensorflow as tf

# --- Sığ Ağ (1 gizli katman) ---
shallow_net = tf.keras.Sequential([
    tf.keras.layers.Dense(16, activation='relu', input_shape=(10,)),  # Giriş→Gizli
    tf.keras.layers.Dense(2),                                          # Gizli→Çıktı
])

# --- Orta Ağ (3 gizli katman) ---
medium_net = tf.keras.Sequential([
    tf.keras.layers.Dense(64,  activation='relu', input_shape=(10,)),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(64,  activation='relu'),
    tf.keras.layers.Dense(2),
])

# --- Derin Ağ (Fonksiyonel API ile) ---
def build_deep_net(input_dim, hidden_dims, output_dim):
    inputs = tf.keras.Input(shape=(input_dim,))
    x = inputs
    for units in hidden_dims:
        x = tf.keras.layers.Dense(units, activation='relu')(x)
    outputs = tf.keras.layers.Dense(output_dim)(x)
    return tf.keras.Model(inputs, outputs)

deep_net = build_deep_net(input_dim=10, hidden_dims=[64, 128, 256, 128, 64], output_dim=3)
deep_net.summary()

# Parametre sayısını gör
total_params = deep_net.count_params()
print(f"Toplam parametre: {total_params:,}")

Kaç Nöron Olmalı?

Az mı? Çok mu? Doğru dengeyi bul

⚖️ Az vs Çok Nöron Karşılaştırması

⚠️ Az Nöron → Underfitting

😰 Çok Az Nöron

  • Model çok basit kalır
  • Örüntüleri öğrenemez
  • Underfitting (yetersiz uyum)
  • Hem train hem test hata büyük
Kapasite: Düşük

✅ Doğru Nöron Sayısı

  • Probleme uygun kapasite
  • İyi genelleme yapar
  • Train ve test hatası dengeli
  • Dropout ile desteklenir
Kapasite: Optimal

😰 Çok Fazla Nöron

  • Eğitim verisini ezberler
  • Yeni veriye genelleşemez
  • Overfitting (aşırı uyum)
  • Yavaş eğitim, yüksek bellek
Kapasite: Aşırı

📏 Nöron Sayısı Seçim Rehberi

🚀
Başlangıç Kuralı

İlk gizli katman: giriş boyutunun 2-4 katı

n_hidden ≈ 2 × n_input
📉
Huni Şekli

Katmanlar ilerledikçe nöron sayısını azalt

[256 → 128 → 64 → 2]
🔬
Deneysel

Farklı mimarileri dene, validation loss'u karşılaştır

Grid Search / Optuna
🛡️
Düzenlileştirme

Fazla nöron için Dropout veya L2 regularization kullan

nn.Dropout(p=0.3)
Python — Nöron Sayısı Denemeleri
# ============================================================
# FARKLI NÖRON SAYILARINI DENE — TensorFlow/Keras
# ============================================================
import tensorflow as tf

def create_model(n_neurons):
    """Verilen nöron sayısıyla model oluştur"""
    return tf.keras.Sequential([
        tf.keras.layers.Dense(n_neurons, activation='relu', input_shape=(10,)),
        tf.keras.layers.Dropout(0.3),              # Overfitting'e karşı
        tf.keras.layers.Dense(n_neurons // 2, activation='relu'),
        tf.keras.layers.Dense(2),
    ])

# Az nöron — Underfitting riski
model_small  = create_model(8)
# Orta — İyi başlangıç noktası
model_medium = create_model(64)
# Fazla — Overfitting riski (Dropout önemli!)
model_large  = create_model(512)

for name, model in [("Az(8)", model_small), ("Orta(64)", model_medium), ("Fazla(512)", model_large)]:
    print(f"{name}: {model.count_params():,} parametre")

# ============================================================
# DROPOUT + BATCHNORM İLE AŞIRI UYUMU ÖNLE
# ============================================================
def build_regularized_net(input_dim, hidden_dim, output_dim, dropout=0.3):
    return tf.keras.Sequential([
        tf.keras.layers.Dense(hidden_dim, input_shape=(input_dim,)),
        tf.keras.layers.BatchNormalization(),      # Normalizasyon
        tf.keras.layers.Activation('relu'),
        tf.keras.layers.Dropout(dropout),          # Rastgele nöron kapatma
        tf.keras.layers.Dense(hidden_dim // 2, activation='relu'),
        tf.keras.layers.Dropout(dropout),
        tf.keras.layers.Dense(output_dim),
    ])

model = build_regularized_net(10, 256, 2, dropout=0.3)
model.summary()

Neden Aktivasyon Fonksiyonu?

Aktivasyon fonksiyonu olmadan, ne kadar katman eklersen ekle, ağın tamamı sadece doğrusal (düz) bir işlem yapar. Aktivasyon fonksiyonları doğrusal olmayan (non-linear) dönüşüm ekleyerek ağın karmaşık örüntüleri öğrenmesini sağlar.

🔍 Aktivasyon Fonksiyonu Keşfedici

f(x) = max(0, x)
Aralık:[0, +∞)
Türev:0 veya 1
Kullanım:Gizli katmanlar
Avantaj:Hızlı, gradient problemi yok
Dezavantaj:Dying ReLU problemi
Negatif değerleri sıfırlar, pozitifleri olduğu gibi geçirir. En yaygın kullanılan aktivasyon fonksiyonu. Derin ağlarda gradient kaybı sorununu büyük ölçüde çözer.

🗺️ Hangi Durumda Hangisini Seç?

Fonksiyon Gizli Katman Çıktı — İkili Sınıf Çıktı — Çok Sınıflı Çıktı — Regresyon
ReLU ✅ İdeal ❌ ❌ ❌
Leaky ReLU ✅ İyi ❌ ❌ ❌
Sigmoid ⚠️ Eski ✅ İdeal ❌ ❌
Tanh ✅ RNN için ⚠️ Olabilir ❌ ❌
Softmax ❌ ❌ ✅ İdeal ❌
Linear (yok) ❌ ❌ ❌ ✅ İdeal
Python — Tüm Aktivasyon Fonksiyonları
# ============================================================
# AKTİVASYON FONKSİYONLARI — TensorFlow/Keras
# ============================================================
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 200)

activations = {
    "ReLU":       tf.keras.activations.relu,
    "Leaky ReLU": lambda x: tf.keras.activations.relu(x, alpha=0.1),
    "Sigmoid":    tf.keras.activations.sigmoid,
    "Tanh":       tf.keras.activations.tanh,
    "GELU":       tf.keras.activations.gelu,
    "Swish":      tf.keras.activations.swish,
    "ELU":        tf.keras.activations.elu,
}

fig, axes = plt.subplots(2, 4, figsize=(14, 6))
axes = axes.flatten()

for i, (name, fn) in enumerate(activations.items()):
    y = fn(x).numpy()
    axes[i].plot(x, y, color='cyan', linewidth=2)
    axes[i].axhline(0, color='gray', linewidth=0.5)
    axes[i].axvline(0, color='gray', linewidth=0.5)
    axes[i].set_title(name, color='white')
    axes[i].set_facecolor('#1a1a2e')
    axes[i].grid(True, alpha=0.2)

plt.tight_layout()
plt.show()

Backprop'un matematiği budur. Çıktıdaki hata, zincir kuralıyla katman katman geriye taşınır:

Python — Backprop & Gradient Descent
# ============================================================
# BACKPROPAGATION — NUMPY İLE SIFIRDAN
# ============================================================
import numpy as np

np.random.seed(0)
W1 = np.random.randn(3, 2) * 0.1
b1 = np.zeros((3, 1))
W2 = np.random.randn(1, 3) * 0.1
b2 = np.zeros((1, 1))

def relu(z):     return np.maximum(0, z)
def sigmoid(z):  return 1 / (1 + np.exp(-z))

def forward(X):
    Z1 = W1 @ X + b1;  A1 = relu(Z1)
    Z2 = W2 @ A1 + b2; A2 = sigmoid(Z2)
    return Z1, A1, Z2, A2

def backward(X, Y, Z1, A1, A2, lr=0.1):
    global W1, b1, W2, b2
    m = X.shape[1]
    dZ2 = A2 - Y
    dW2 = (dZ2 @ A1.T) / m;  db2 = dZ2.mean(axis=1, keepdims=True)
    dA1 = W2.T @ dZ2
    dZ1 = dA1 * (Z1 > 0)                 # ReLU türevi
    dW1 = (dZ1 @ X.T) / m;  db1 = dZ1.mean(axis=1, keepdims=True)
    W2 -= lr * dW2;  b2 -= lr * db2
    W1 -= lr * dW1;  b1 -= lr * db1

X = np.array([[0,0,1,1],[0,1,0,1]])
Y = np.array([[0,1,1,0]])               # XOR

for epoch in range(1000):
    Z1, A1, Z2, A2 = forward(X)
    loss = -np.mean(Y*np.log(A2+1e-8) + (1-Y)*np.log(1-A2+1e-8))
    backward(X, Y, Z1, A1, A2, lr=0.5)
    if epoch % 200 == 0:
        print(f"Epoch {epoch}  |  Loss: {loss:.4f}")

# TensorFlow/Keras — Otomatik Backprop (GradientTape)
import tensorflow as tf
import numpy as np

model   = tf.keras.Sequential([
    tf.keras.layers.Dense(8, activation='relu', input_shape=(2,)),
    tf.keras.layers.Dense(1, activation='sigmoid'),
])
optimizer = tf.keras.optimizers.Adam(learning_rate=0.01)
loss_fn   = tf.keras.losses.BinaryCrossentropy()

X_t = tf.constant([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
Y_t = tf.constant([[0.],[1.],[1.],[0.]])

for epoch in range(500):
    with tf.GradientTape() as tape:   # Backprop bölgesini başlat
        pred = model(X_t, training=True)
        loss = loss_fn(Y_t, pred)
    gradients = tape.gradient(loss, model.trainable_variables)
    optimizer.apply_gradients(zip(gradients, model.trainable_variables))
    if epoch % 100 == 0:
        print(f"Epoch {epoch}  |  Loss: {loss.numpy():.4f}")

# --- Ya da daha kısa: model.compile + model.fit ---
model.compile(optimizer='adam', loss='binary_crossentropy')
model.fit(X_t, Y_t, epochs=500, verbose=0)
print("Tahminler:", model.predict(X_t).round())

Loss Fonksiyonları

Modelin ne kadar yanıldığını ölçen pusula

🎯

Loss Nedir?

Loss (kayıp) fonksiyonu, modelin tahmininin gerçek değerden ne kadar uzak olduğunu ölçer. Eğitimin amacı bu değeri minimize etmektir.

🔍 Loss Fonksiyonu Karşılaştırıcı

L = (1/n) Σ(y − ŷ)²
Görev:Regresyon
Avantaj:Büyük hataları quadratik cezalandırır
Dezavantaj:Aykırı değerlere hassas
TensorFlow:tf.keras.losses.MeanSquaredError()
MSE: Tahmin ile gerçek farkının kareleri. Regresyon için standart seçimdir.

🧮 Canlı Loss Hesaplayıcı

Tahmin ve gerçek değerleri ayarla, tüm loss değerlerini karşılaştır

Python — Tüm Loss Fonksiyonları
# ============================================================
# LOSS FONKSİYONLARI — TensorFlow/Keras
# ============================================================
import tensorflow as tf
import numpy as np

y_true = tf.constant([1.0, 0.0, 1.0, 1.0])
y_pred = tf.constant([0.8, 0.2, 0.6, 0.9])

# Regresyon
mse = tf.keras.losses.MeanSquaredError()
mae = tf.keras.losses.MeanAbsoluteError()
huber = tf.keras.losses.Huber(delta=0.5)
print(f"MSE:   {mse(y_true, y_pred).numpy():.4f}")
print(f"MAE:   {mae(y_true, y_pred).numpy():.4f}")
print(f"Huber: {huber(y_true, y_pred).numpy():.4f}")

# İkili Sınıflama
bce = tf.keras.losses.BinaryCrossentropy()
print(f"BCE:   {bce(y_true, y_pred).numpy():.4f}")

# Çok Sınıflı (one-hot)
y_true_cat = tf.constant([[1,0,0],[0,0,1],[0,1,0]], dtype=tf.float32)
y_pred_cat = tf.nn.softmax(tf.random.normal((3, 3)))
cce = tf.keras.losses.CategoricalCrossentropy()
print(f"CrossEntropy: {cce(y_true_cat, y_pred_cat).numpy():.4f}")

# Hangi loss ne zaman?
# Regresyon     → MeanSquaredError / Huber
# İkili sınıf   → BinaryCrossentropy
# Çok sınıflı   → CategoricalCrossentropy / SparseCategoricalCrossentropy

# ============================================================
# CNN MİMARİSİ — TensorFlow/Keras
# ============================================================
import tensorflow as tf

def build_simple_cnn(num_classes=10):
    return tf.keras.Sequential([
        # Konvolüsyon Bloku 1
        tf.keras.layers.Conv2D(32, (3,3), activation='relu',
                               padding='same', input_shape=(28,28,1)),  # → (28,28,32)
        tf.keras.layers.MaxPooling2D((2,2)),                            # → (14,14,32)

        # Konvolüsyon Bloku 2
        tf.keras.layers.Conv2D(64, (3,3), activation='relu', padding='same'),  # → (14,14,64)
        tf.keras.layers.MaxPooling2D((2,2)),                                   # → (7,7,64)

        # Flatten + Fully Connected katmanları
        tf.keras.layers.Flatten(),             # → (64*7*7 = 3136)
        tf.keras.layers.Dense(128, activation='relu'),
        tf.keras.layers.Dropout(0.3),
        tf.keras.layers.Dense(num_classes, activation='softmax'),  # Ham logit yerine softmax
    ])

model = build_simple_cnn(num_classes=10)
model.summary()
print(f"Toplam Parametre: {model.count_params():,}")

# ============================================================
# EĞİTİM — MNIST örneği
# ============================================================
# MNIST verisetini TensorFlow ile yükle
(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data()

# Normalize ve şekil düzenle: (N, 28, 28) → (N, 28, 28, 1), 0-1 arası
X_train = X_train[..., tf.newaxis].astype('float32') / 255.0
X_test  = X_test[..., tf.newaxis].astype('float32') / 255.0

model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy'],
)

history = model.fit(
    X_train, y_train,
    epochs=5,
    batch_size=64,
    validation_split=0.1,
)

test_loss, test_acc = model.evaluate(X_test, y_test, verbose=0)
print(f"Test Acc: {test_acc*100:.2f}%")
